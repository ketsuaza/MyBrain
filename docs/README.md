# 読書メモ

『本を読む本』の点検読書・分析読書を、欄を選んで埋めていく HTML。

分析読書の規則1〜15のラベルは、訳書（講談社学術文庫）の「分析読書の三段階のまとめ」の文言である。章の中の規則の文言は、各欄の説明（？）に引いてある。規則12〜14は反対の根拠、規則15は判断保留の根拠として書く（まとめの注による）。前の版（規則11まで）で保存した読書メモは、「読み込む」と新しい形に直る。

- iPhone など: https://ketsuaza.github.io/MyBrain/ （GitHub Pages。`main` の `docs/` が出る）
- Mac: この `docs/index.html` をブラウザで開く

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 入力する画面 |
| `factcheck.js` | Agent のファクトチェックの結果の正本。HTML が読んで、規則9の命題の下に出す |
| `sample.js` | 動作確認用のサンプル。HTML が初回だけ読み込む |

写しは置かない。ツールの正本はこの `docs/` だけである。

## データの出どころ

| データ | 出どころ | 読むとき |
| --- | --- | --- |
| ブックリスト（書名、等級、評価、読書状況） | リポジトリ直下の `book_principles.json`。GitHub の `main` から読む | HTML を開くたび |
| 著者・出版社・刊行日 | openBD | 「本を足す」で本を選んだとき |

- ブックリストに出るのは、`main` に入った内容である。手元の未マージの変更は出ない。反映は最大5分遅れる。
- 通信できないときは、ブックリストが空になる。書誌は欄に直接書ける。

## 保存

正本は vault の `60_notes/読書メモ/{書名}.md`。HTML の「Obsidian に保存」で書き出す。
入力中の状態はブラウザに残る。Mac と iPhone では別々になるので、受け渡しは、保存した Markdown を「読書メモから読み込む」に貼る。

## 公開の範囲

このリポジトリは公開である。`factcheck.js` には、読書メモに書いた命題の文が入る。読書メモの本文は入らない。

## テストとデータのガード

道具はリポジトリ直下にある。初めに `npm run setup` を1回行う（Playwright と Chromium を入れ、pre-commit のフックをつなぐ）。
`node_modules` は iCloud に同期されないよう、`node_modules.nosync` へのリンクになっている。

| コマンド | すること |
| --- | --- |
| `npm test` | E2E の仕様（`tests/e2e/`）とガードの仕様（`tests/guard/`）を全部実行する |
| `npm run e2e` | E2E の仕様だけ。主な状態のスクリーンショットを `screenshots/` に撮る |
| `npm run guard` | コミットしようとしている版を HEAD と比べ、件数を出す |

E2E の仕様が扱うこと: ブックリストの全件の表示と並べ替え、1280x800 でダイアログがスクロールしないこと（一覧の表の縦だけは中でスクロールする）、規則1〜15のラベルがまとめの文言と同じこと、各規則の欄の働き、前の形の読書メモの移行、命題どうしを3クリック以内でつなげること、保存した Markdown が有効なこと、サンプルの命題にファクトチェックの結果が出ること、390px の幅で横にはみ出さないこと。

pre-commit のフック（`.githooks/pre-commit` → `scripts/guard-data.js`）は、`book_principles.json`、`factcheck.js`、`sample.js` が消えたり空になったり、件数（本、命題、サンプル）が HEAD から10%を超えて減ったりすると、コミットを止める。意図して減らすときは `git commit --no-verify` で通す。

## Agent の作業

手順は、スキル `reading-memo`（`~/.skillport/skills/reading-memo`）にある。

- 命題のファクトチェック: 「読書メモ『書名』の命題をファクトチェックして」
- 用語集への追加: 「読書メモ『書名』の用語を用語集に入れて」

`factcheck.js` は、スキルの `scripts/write_factcheck.py` で書く。手で書き換えない。
