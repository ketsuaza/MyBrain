# 読書メモ

『本を読む本』の点検読書・分析読書を、欄を選んで埋めていく HTML。

- iPhone など: https://ketsuaza.github.io/MyBrain/ （GitHub Pages。`main` の `docs/` が出る）
- Mac: この `docs/index.html` をブラウザで開く

## ファイル

| ファイル | 役割 |
| --- | --- |
| `index.html` | 入力する画面 |
| `factcheck.js` | Agent のファクトチェックの結果の正本。HTML が読んで、規則10の命題の下に出す |
| `sample.js` | 動作確認用のサンプル。HTML が初回だけ読み込む |

写しは置かない。ツールの正本はこの `docs/` だけである。

## データの出どころ

| データ | 出どころ | 読むとき |
| --- | --- | --- |
| ブックリスト（書名、等級、評価、読書状況） | リポジトリ直下の `book_principles.json`。GitHub の `main` から読む | HTML を開くたび |
| 著者・出版社・刊行日 | openBD | 「本を足す」で本を選んだとき |

- ブックリストに出るのは、`main` に入った内容である。手元の未マージの変更は出ない。反映は最大5分遅れる。
- 通信できないときは、ブックリストが空になる。書誌は欄に直接書ける。

## 保存

正本は vault の `60_notes/読書メモ/{書名}.md`。HTML の「Obsidian に保存」で書き出す。
入力中の状態はブラウザに残る。Mac と iPhone では別々になるので、受け渡しは、保存した Markdown を「読書メモから読み込む」に貼る。

## 公開の範囲

このリポジトリは公開である。`factcheck.js` には、読書メモに書いた命題の文が入る。読書メモの本文は入らない。

## Agent の作業

手順は、スキル `reading-memo`（`~/.skillport/skills/reading-memo`）にある。

- 命題のファクトチェック: 「読書メモ『書名』の命題をファクトチェックして」
- 用語集への追加: 「読書メモ『書名』の用語を用語集に入れて」

`factcheck.js` は、スキルの `scripts/write_factcheck.py` で書く。手で書き換えない。
